# dragonhound

**Python backend, ML tooling and DevOps/QA. Remote, Australia.**

I build APIs, CI/CD and developer tooling. I spent 2018–2026 at Komodo Platform, going from support to Chief Quality Officer, after a decade in public-sector geospatial. I now publish open-source tools as [Dragonhound Labs](https://dragonhound.dev/).

**[dragonhound.dev](https://dragonhound.dev/)** has live demos of the tools.

## Selected work

**Open source**

- **[ai-code-auditor](https://github.com/smk762/ai-code-auditor)**: turns repo findings into work packs for coding agents. Bug and security fixes need a failing-then-passing test or a written waiver
- **[argus-curator](https://github.com/smk762/argus-curator)**: image dataset curation and moderation, with a reason recorded for every exclusion
- **[argus-iris](https://github.com/smk762/argus-iris)**: GPU lease broker for mixed workloads on a small fleet
- **[argus-halo](https://github.com/smk762/argus-halo)**: Terraform for Hetzner and Cloudflare, with credential-free tests
- **[argus-survey](https://github.com/smk762/argus-survey)**: point clouds to survey deliverables, with every datum and command recorded

**Komodo / Gleec**

- **[defi_stats](https://github.com/GLEECBTC/defi_stats)**: Python API for DEX network trading statistics ([live API docs](https://defistats.gleec.com/docs))
- **[komodo-docs-mdx](https://github.com/GLEECBTC/komodo-docs-mdx/commits?author=smk762)**: API documentation, with validators for parameter tables and request/response examples ([published docs](https://gleec.com/komodo/docs/komodo-defi-framework/api/))
- **[Gleec Wallet](https://github.com/GLEECBTC/gleec-wallet/commits?author=smk762)**: QA lead, CI/CD, and bugfix and feature commits

**Stack:** Python · FastAPI · PostgreSQL · Redis · Docker · Linux · GitHub Actions · Terraform · GDAL
